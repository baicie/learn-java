## 7. Playwright 企业验收

### 场景 1：IAM

```text
1. 管理员登录。
2. 创建“巡检管理员”角色。
3. 勾选：
   - work-record:read:all
   - work-record:write
   - work-record:template:read
4. 设置工作记录数据范围 ALL。
5. 创建 Alice。
6. 给 Alice 分配巡检管理员。
7. Alice 登录。
8. Alice 可进入记录列表和设计器只读页。
9. Alice 看不到用户管理和角色权限。
10. 管理员移除 template:read。
11. Alice 刷新后访问设计器返回 403。
12. 审计日志包含角色、权限和用户绑定变更。
```

### 场景 2：设计器

```text
1. 新建日报模板。
2. 从左侧拖入文本、日期、字典单选。
3. 新建两列 Grid 并移动字段。
4. 修改字段标题、必填和字典编码。
5. 保存草稿。
6. 刷新页面，文档完整恢复。
7. 预览使用真实 Shadcn 控件填写。
8. 发布 v1。
9. 新建一条 v1 记录。
10. 编辑模板增加“明日计划”并发布 v2。
11. v1 详情不显示明日计划。
12. v2 新建表单显示明日计划。
```

### 场景 3：历史字段风险

```text
1. v1 发布 priority 字段并创建历史记录。
2. v2 在设计器点击删除 priority。
3. 展示“字段已被历史记录引用”确认。
4. 确认后字段变成 disabled。
5. v1 详情仍显示 priority label。
6. v2 新建表单不显示 priority。
```

## 10. CI 防回归

```bash
#!/usr/bin/env bash
set -euo pipefail

if grep -R --line-number "@faker-js/faker" \
  web/portal/src/features/platform-users \
  web/portal/src/features/users 2>/dev/null; then
  echo "Faker is forbidden in platform user pages." >&2
  exit 1

  -E "Secured by Clerk|cashier|manager|invited|suspended" \
  web/portal/src/features web/portal/src/components/layout; then
  echo "Shadcn Admin demo content remains." >&2
  exit 1
fi

  web/portal/src/features/work-records; then
```

## 13. 性能验收

```text
用户列表 API P95 < 500ms
角色详情 API P95 < 500ms
100 字段设计器首次可交互 < 2s
属性编辑到画布刷新 < 100ms
撤销/重做 < 100ms
拖拽过程中不重新编译整个表单
```

优化方式：

- 节点级 `memo`；
- `useDesignerStore(selector)` 避免全 Store 重渲染；
- schema 编译 debounce；
- DragOverlay 使用轻量缩略图；
- 字典 Query 按 dictCode 缓存；
- 不在每个键盘输入时执行 Schema Diff。
