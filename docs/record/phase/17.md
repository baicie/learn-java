# Phase 17：测试体系补齐

## 一、结论

本阶段以 `b6680a1` 为源码基线。

当前并不是“完全没有测试”：

- `DictionaryServiceTest` 已覆盖字典创建、修改、禁用、审计和禁用项查询。
- `CalendarServiceTest` 已覆盖年度日历、工作日推导、节假日、CSV 导入和审计。
- Schema、字段索引、动态字段校验、动态筛选、权限、导出都已有部分测试。
- 前端已经配置 Vitest Browser + Playwright Chromium。

真正的问题是：

```text
1. 测试按 Phase 编号不断叠加，重复 Fixture 很多。
2. Service 单测较多，但 Controller、真实 PostgreSQL、跨版本契约不足。
3. 字符串 SQL 断言不能证明 SQL 真能执行。
4. 前端新增了孤立组件测试，但真实业务路径测试不足。
5. CI 运行 test，不运行后端 IT 和前端 coverage。
6. 覆盖率没有门禁。
7. 测试命名没有区分单元测试和集成测试。
```

本阶段应重构为：

```text
纯单元测试          *Test

架构测试            *ArchitectureTest
```

## P0-1：`contains_any` 当前生成非法 SQL

当前实现没有在多个 OR 分支前追加 `and (`，每个分支自身的括号也没有闭合。现有测试只检查 SQL 包含 `jsonb_typeof` 和参数，没有真实执行 SQL，因此没有发现。

替换 `WorkRecordJsonbFilterSqlBuilder.appendContainsAny()`：

```java
private void appendContainsAny(
    StringBuilder where,
    Map<String, Object> params,
    RecordDynamicFilter filter,
    int index,
    String keyParam) {
  requireValues(filter);

  where.append(" and (");

  for (int valueIndex = 0;
      valueIndex < filter.values().size();
      valueIndex++) {
    if (valueIndex > 0) {
      where.append(" or ");
    }

    String valueParam =
        "dfAny" + index + "_" + valueIndex;

    params.put(
        valueParam,
        String.valueOf(
            filter.values().get(valueIndex)));

    where
        .append("(jsonb_typeof(")
        .append(jsonExpr(keyParam))
        .append(") = 'array' and ")
        .append("custom_data_json @> ")
        .append("jsonb_build_object(")
        .append("cast(:")
        .append(keyParam)
        .append(" as text), ")
        .append("jsonb_build_array(")
        .append("to_jsonb(cast(:")
        .append(valueParam)
        .append(" as text)))))");
  }

  where.append(") ");
}
```

新增结构测试：

```java
@Test
```

# 三、测试分层

| 测试层              | 主要职责                       | 是否启动 Spring | 是否启动 PostgreSQL |
| ------------------- | ------------------------------ | --------------: | ------------------: |
| Domain/规则测试     | fieldCode、保留字段、值类型    |              否 |                  否 |
| Service 测试        | 权限、调用顺序、审计、版本选择 |              否 |                  否 |
| Controller Web 测试 | HTTP、权限码、JSON、错误码     |       MVC Slice |                  否 |
| Repository IT       | SQL、JSONB、租户隔离、迁移契约 | 否或最小 Spring |                  是 |
| ArchUnit            | 分层和依赖方向                 |              否 |                  否 |
| 前端纯函数          | schema builder、dict injector  |              否 |                  否 |
| 前端组件            | 表单、设计器、列表、导出弹窗   |          浏览器 |                  否 |

## 强制风险映射

| 强制风险               | 测试归属                                           |
| ---------------------- | -------------------------------------------------- |
| fieldCode 正则         | `FieldCodeRulesTest`、前端 schema-builder          |
| 保留字段               | `FieldCodeRulesTest`、Schema Service、前端 builder |
| 字典字段非法值         | `WorkRecordValueValidatorTest`                     |
| 禁用字典项历史回显     | Dictionary Adapter、导出、详情页                   |
| 字段删除后历史记录展示 | Schema builder、Readonly View                      |
| 普通用户越权           | Permission、Query Service、Controller              |
| 导出字段权限           | Export Service、Export Dialog                      |
| 动态筛选白名单         | Dynamic Filter Policy                              |
| JSONB 查询参数化       | SQL Builder + PostgreSQL IT                        |
| 模板版本兼容           | Filter Policy、Export Service、Readonly View       |
